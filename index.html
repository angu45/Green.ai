About Nova AI Studio

This is a deployable starter workspace, not a full frontier AI model. The no-API mode uses prompt routing, templates and browser-side utilities. It can draft structured starter content, generate prompt ideas and export text.

  • Chat history is stored in this browser's localStorage.
  • Image Lab creates prompts and simple SVG artwork, not photorealistic AI images.
  • Real generative language/image models require downloading compatible model weights or connecting a hosted model/API.
  • Never paste secrets or sensitive information into a public demo.
